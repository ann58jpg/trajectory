# «Траектория» — ИИ-навигатор выбора образования

Рабочий прототип для школьников всей России: анкета → персональные рекомендации профессий, специальностей и вузов
**не по бренду, а по результатам** — спрос, доход, трудоустройство и перспектива профессии через 5 лет в регионе пользователя.

Переключатель **«По интересам | По доходу»**, игра «Что бы ты делал(а) завтра на работе?», «Если готов изменить»,
сравнение 2–4 вариантов, статус профессии (🟢/🟡/🔴), регион как жёсткий фильтр и мероприятия вузов.
Каталог: 281 направление в 56 группах, 210 профессий, 240 вузов и колледжей в 76 регионах всех 8 федеральных округов.

## Запуск

```bash
npm install && npm run setup && npm run dev
```

Откройте http://localhost:3000. Нужен Node.js ≥ 20.9.

- `npm run setup` — миграция SQLite (drizzle), zod-валидация справочников `data/*.json` и загрузка их в БД; печатает число записей.
- Сайт **работает без API-ключа**: в шапке бейдж «Демо-режим (без ИИ)», всё считает детерминированный движок, тексты — из шаблонов.
- Если `npm run setup` не запускали, приложение всё равно поднимется: справочники вшиты в сборку как фолбэк.

| Команда | Что делает |
|---|---|
| `npm run dev` / `build` / `start` | разработка / сборка / прод-сервер |
| `npm test` | unit-тесты (vitest): движок, персоны, игра, покрытие всех 56 групп, тексты без запрещённых слов, воронка |
| `npm run test:e2e` | e2e (Playwright, ширина 375px): анкета с игрой, персоны, переключатель, сравнение, DataGap, воронка, «Мой план» |
| `npm run gen:catalog` | пересобрать каталог из `scripts/data_src/*.py` (+ `python3 scripts/gen-task-cards.py` для карточек игры) |
| `npm run import:tabiturient` | импорт направлений, ДОД и проходных с tabiturient.ru в `data/import/` (с паузами, источник в файле) |
| `npm run validate:data` | проверка справочников: схема, ссылочная целостность, «нет тупиков» |
| `npm run check-links` | проверка ссылок на сайты вузов (нужен открытый интернет) |
| `npm run typecheck` | TypeScript |

Для e2e нужен Chromium для Playwright (`npx playwright install chromium`) или путь к браузеру в `PW_CHROMIUM_PATH`.

## Деплой на Vercel

Ничего настраивать не нужно: импортируйте репозиторий в Vercel (**Add New → Project → Import**) и нажмите **Deploy**.

- Сборка запускает `npm run vercel-build` = `npm run setup && next build`: миграция, проверка справочников и seed SQLite выполняются при каждом деплое (см. `vercel.json`).
- Файл `data/trajectory.db` включается в серверные функции (`outputFileTracingIncludes` в `next.config.ts`) вместе с нативным модулем `better-sqlite3`. Node.js — 22.x (поле `engines`).
- На Vercel файлы функции только для чтения, поэтому при первом запросе база копируется в `/tmp`: там работает кэш hh.ru и ответов ИИ. Кэш живёт, пока жив инстанс функции, и не общий для инстансов — для прототипа этого достаточно. Если копирование не удастся, база откроется только для чтения, а кэш уйдёт в память.
- Справочники меняются через `data/*.json` и новый деплой.
- Переменные окружения необязательны (без них — демо-режим): `ANTHROPIC_API_KEY`, `ANTHROPIC_MODEL`, `HH_USER_AGENT`, `NEXT_PUBLIC_YM_ID`, `DATABASE_URL`, `ADMIN_PASSWORD` — задаются в **Settings → Environment Variables** (см. «Аналитика воронки»).

Локально сборку под Vercel можно проверить командой `npx vercel build`.

## Аналитика воронки

Все события идут через `track(event, props)` из `lib/analytics.ts`: в Яндекс Метрику (`reachGoal`) и в `POST /api/track`.
Личных данных нет: только анонимный id сессии (случайный, в localStorage), название события и короткие параметры (режим, блок анкеты, оценка).

| Переменная | Зачем |
|---|---|
| `NEXT_PUBLIC_YM_ID` | номер счётчика Метрики; включает счётчик с вебвизором и картой кликов |
| `DATABASE_URL` | внешняя БД для событий: Neon (`postgres://…`) или Turso (`libsql://…`, плюс `DATABASE_AUTH_TOKEN`). Таблица `track_events` создаётся сама. Без переменной события пишутся в консоль и в память процесса |
| `ADMIN_PASSWORD` | пароль для `/admin/funnel` (без него страница закрыта) |

События: `landing_view`, `quiz_start`, `quiz_block_done` (`block`: A–E), `quiz_complete`, `results_view`, `mode_switch`,
`profession_open`, `university_open`, `event_click`, `plan_add`, `compare_open`, `report_download`, `report_share`, `feedback` (`rating`: 1–5).

Конверсии (уникальные сессии, `lib/funnel.ts`):
- начали анкету = `quiz_start / landing_view`; закончили = `quiz_complete / quiz_start`; дошли до подборки = `results_view / quiz_complete`;
- вовлечение = сессии с `profession_open | university_open | event_click | compare_open` / `results_view`;
- план = `plan_add / results_view`; отчёт = `report_download | report_share` / `results_view`;
- где уходят из анкеты — доля сессий, закончивших блоки A–E, от начавших.

`/admin/funnel` (пароль `ADMIN_PASSWORD`): шаги воронки, конверсии, уход по блокам анкеты, средняя оценка «Тебе это помогло?», график по дням; фильтры по датам и режиму.

**Цели в Метрике.** В интерфейсе Метрики: *Настройка → Цели → Добавить цель → тип «JavaScript-событие»*, идентификатор цели — название события
(`quiz_start`, `quiz_complete`, `results_view`, `plan_add`, `report_download`, `feedback` и т. д.). Составную цель-воронку можно собрать из
`landing_view → quiz_start → quiz_complete → results_view → plan_add`. Вебвизор и карта кликов включаются кодом счётчика автоматически.

## Режим презентации и пробелы в данных

- Правило показа цифр: подтверждено → цифра с источником; оценка → цифра с пометкой «оценка»; данных нет → рамка `DataGap` («Подтверждённых данных нет», что здесь должно быть и где это взять).
- `/data-gaps` — сводка пробелов по каталогу с владельцами данных (СФР, ФНС, вузы, hh.ru, Минобрнауки, Минтруд).
- `/admin` → «Режим презентации»: скрывает все оценки, остаются только подтверждённые цифры.

## Как подключить ИИ

Скопируйте `.env.example` в `.env` и задайте ключ:

```
ANTHROPIC_API_KEY=sk-ant-...
ANTHROPIC_MODEL=claude-sonnet-5-5   # по умолчанию
```

С ключом появляются:
- **разбор свободного текста** («Кем хочешь стать и почему?») → теги интересов, ценности, опасения (zod-схема `DreamParse`);
- **персональные объяснения** на карточках: «почему тебе», «день из жизни», «что спросить у студентов» — на вход подаются только факты из БД, системный промпт запрещает добавлять числа;
- **свежие мероприятия вуза** на ближайшие 60 дней через серверный инструмент `web_search_20260209` (версию можно сменить через `ANTHROPIC_WEB_SEARCH_TOOL`). Событие без реальной ссылки или с прошедшей датой отбрасывается; кэш 12 ч.

Каждый вызов: таймаут (20 с, для веб-поиска 45 с) → один повтор → фолбэк на шаблоны и seed. Ответы проходят zod-схемы.
Включён серверный фолбэк при отказе модели (`fallbacks: "default"`, бета `server-side-fallback-2026-07-01`): если модель откажется отвечать, запрос автоматически перезапустится на резервной модели. Отключить — убрать эти два поля в `lib/llm/anthropic.ts`.

`LLM_PROVIDER=yandexgpt | gigachat` — заглушки `YandexGPTProvider` и `GigaChatProvider` с тем же интерфейсом (`lib/llm/stubs.ts`) под будущее госвнедрение; сейчас они не реализованы, поэтому включается демо-режим. `LLM_PROVIDER=none` — принудительно демо-режим.

**hh.ru**: модуль `lib/sources/hh.ts` берёт число вакансий и медиану зарплат из публичного API (`api.hh.ru/vacancies`, заголовок `HH-User-Agent` из `HH_USER_AGENT`), кэширует в SQLite на 24 ч и при любой ошибке (403, таймаут, нет сети) молча отдаёт seed-оценку. Используется на карточке профессии.

### Движок (кратко)

`Score = Σ wₖ(t) · фактор_k + бонус`, все факторы в 0..1:

- **Спрос** — вакансии в регионах, доступных при твоей готовности к переезду (доля региона × отраслевой буст), лог-нормировка + тренд.
- **Доход** — зарплата через 3–5 лет и потолок в городе проживания или лучшем доступном городе (с поправкой на стоимость жизни; удалёнка частично подтягивает к уровню крупных городов).
- **Трудоустройство** — доля трудоустроенных по специальности и скорость выхода на работу.
- **Приоритет** — госприоритеты, статус 🟢/🟡/🔴, минус риск автоматизации ИИ.
- **Метч** — теги интересов из предметов (с весами «почему нравится»: «интересно само по себе» 1.0 … «оценки хорошие, но не нравится» 0.2), хобби, свободного текста, достижений; тип Климова из 6 пар; формат работы; «руками/головой».

Ползунок `t`: 0 — Интересы (Метч 0.45…), 0.5 — базовая формула модели (0.30/0.25/0.20/0.15/0.10), 1 — Деньги (Доход 0.40…, порог метча ≥ 0.25). Интерполяция кусочно-линейная, пересчёт на клиенте.
Горизонт «деньги нужны сразу» даёт бонус за ранний вход, вечернюю/дуальную/онлайн-форму, колледж, и штраф за обучение от 6 лет.

### Как менять веса

- Постоянно: `lib/engine/config.ts` → `WEIGHT_ANCHORS` (три профиля) и `ENGINE` (порог метча, минимальный выигрыш компромисса, бонусы горизонта, удалёнка).
- Для демонстрации: страница **/admin/weights** — ползунки по каждому профилю (сумма весов автоматически остаётся 1), изменения сохраняются в браузере и сразу применяются на экране результатов.

| Справочник | Объём |
|---|---|
| `regions.json` | 24 региона РФ + «зарубежье»: коэффициент зарплаты, медиана, аренда, бюджет студента, города, отрасли, работодатели, соседи, id региона на hh.ru |
| `specialties/NN.json` | 281 направление в 56 группах (перечень как на tabiturient.ru/np): ЕГЭ, доп. экзамены, теги, дисциплины, профессии; генерирует `scripts/gen-catalog.py` |
| `professions.json` | 74 профессии: задачи, стек, зарплаты junior/middle/senior/потолок, ранний вход, удалёнка, статус на 5 лет с обоснованием, риск ИИ, госприоритеты, «день из жизни» |
| `universities.json` | 62 вуза и колледжа в 28 городах, включая все из вопроса 18 и Рурский/Мичиганский университеты с пометкой «за рубежом» |
| `programs.json` | 245 программ (вуз × направление): проходной (диапазон), бюджет/целевые места, цена, формы, расписание, партнёры |
| `events.json` | 140 типовых мероприятий без выдуманных дат, со ссылками на официальные сайты |
| `priorities.json` | 16 госприоритетов (Указ № 309, нацпроекты технологического лидерства, «Кадры») |

Правила:
- У каждой группы чисел есть `source`, `updatedAt`, `confidence` (`verified` / `estimate`); в UI рядом с цифрой — значок источника, у оценок — «оценка».
- **Проверено (verified)**: медиана зарплат по РФ 73 871 ₽ (Росстат, апрель 2025) — база региональных коэффициентов; план приёма РНИМУ им. Пирогова на «Лечебное дело» в 2025 году (810 бюджетных и 485 целевых мест).
  Использованы как ориентиры: медиана предлагаемых зарплат на hh.ru (≈75 500 ₽, июнь 2025), средняя зарплата DevOps-инженеров ≈219 тыс. ₽ (hh.ru, май 2025), средняя цена платного года ≈224 тыс. ₽ (hh.ru Карьера), средние баллы ЕГЭ поступивших в 2025 году (МФТИ — 96,8, бюджет МГТУ им. Баумана — 85,7).
- **Всё остальное — `estimate`**: региональные коэффициенты, зарплаты по профессиям, проходные баллы (даются диапазоном), цены, рейтинги, доли трудоустройства. Точные проходные 2025 года по большинству программ в открытом доступе найти не удалось, поэтому они не выдуманы, а даны как «≈ мин–макс, оценка» со ссылкой «проверь на сайте вуза».
- Даты мероприятий в seed не выдумываются (`date: null`). Свежие даты появляются только с ИИ-поиском и реальной ссылкой.
- Персональные данные (152-ФЗ): ФИО не спрашиваем, анкета хранится только в `localStorage` браузера и передаётся в теле запроса; сервер её не сохраняет (кэшируются только ответы ИИ по хэшу текста).

## Ограничения прототипа

- Зарплаты и проходные баллы — оценки; перед использованием в реальном сервисе нужно подтянуть мониторинг Минобрнауки, приказы о зачислении и API hh.ru с токеном.
- Из песочницы разработки не было доступа к сайтам вузов и hh.ru, поэтому ссылки с непроверенными путями заменены корнем официального сайта (`npm run check-links` проверит их там, где есть интернет), а рынок труда работает на seed-оценках.
- ИИ-часть написана по документации и типам SDK, но без живого ключа в среде разработки не прогонялась; без ключа и при любой ошибке ИИ работает фолбэк на шаблоны (проверено с неверным ключом).
- Набор вузов (62) и программ (245) — выборка, а не полный реестр; у колледжей СПО конкурс считается по среднему баллу аттестата.
- «Скачать PDF» — через диалог печати браузера («Сохранить как PDF»).

Решения, принятые по ходу работы, — в [DECISIONS.md](./DECISIONS.md).
